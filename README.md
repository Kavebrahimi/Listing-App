A modern **Single Page Application (SPA)** built from scratch with Laravel, Vue.js, Inertia.js, Tailwind CSS, and Ziggy.js. Designed to provide a smooth and intuitive experience for users and admins alike.

---

## 🌟 Features

- **Request Management:** Create, edit, delete, and track requests.  
- **Admin Approval:** Requests must be verified by an admin before publishing.  
- **User Authentication:** Email verification, secure login, profile editing, and account management.  
- **Dark Mode Support:** Seamless light/dark theme toggle.  
- **SPA Experience:** Fast navigation without page reloads.  
- **Optimized Database:** MySQL backend with eager loading to prevent N+1 queries.  
- **Persian Localization:** Full Farsi interface and messages.  

---

## 🛠 Tech Stack

- **Backend:** Laravel  
- **Frontend:** Vue.js + Inertia.js + Tailwind CSS  
- **Routing:** Ziggy.js  
- **Database:** MySQL  

---

## ⚠️ Notes

- `.env` file is excluded for security; create your own when running locally.  
- All authentication and authorization are custom-built to ensure a secure environment for both users and admins.

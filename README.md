Persian SPA Request Management App

A fully-featured Single Page Application (SPA) built from scratch with Laravel, Vue.js, Inertia.js, Tailwind CSS, and Ziggy.js.

Features

Request Management: Users can create, edit, delete, and view requests.

Admin Approval: Requests must be approved by an admin before publishing.

User Authentication: Email verification, profile editing, and account management.

Dark Mode: Seamless dark/light theme support.

SPA Experience: Smooth navigation without page reloads.

Database: MySQL with optimized queries to prevent N+1 problems.

Fully Localized: All messages and UI in Persian (Farsi).

Tech Stack

Backend: Laravel

Frontend: Vue.js + Inertia.js + Tailwind CSS

Routing: Ziggy.js

Database: MySQL

Note: .env file is excluded for security. Please create your own .env when running locally.
